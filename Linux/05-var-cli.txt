= Variable data
/var 

/var stores data that changes frequently while the Linux system is running.

eg:
Logs are continuously created and updated.
Databases change.
Application data changes.
Queues change.
Temporary application data may change


eg:
/var
├── cache
├── lib
├── log
├── mail
├── opt
├── run
├── spool
└── tmp

important:
/var/log
/var/lib
/var/cache
/var/run
/var/tmp

---------------------------------------------
= contains system and application logs.
/var/log/
├── auth.log
├── syslog
├── kern.log
├── nginx/
├── apache2/
└── ...


= What is a log?
A log is a record of what happened.


cat /var/log/syslog
less /var/log/syslog
tail /var/log/syslog
tail -n 20 /var/log/syslog      // Show the last 20 lines
tail -f /var/log/syslog         // real-time log  // -f means follow

= store persistent application/system state(Data that applications need to keep between restarts)
/var/lib

eg:
/var/lib/docker
/var/lib/mysql
/var/lib/postgresql
/var/lib/apt

eg: docker
/var/lib/docker
│
├── containers
├── image
├── volumes
└── ...

---------------------------------------------
= store cached data(data saved temporarily so the system can access it faster later)
/var/cache

eg:
/var/cache/apt/archives
