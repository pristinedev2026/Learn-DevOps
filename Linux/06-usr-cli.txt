= /usr(Unix System Resources)
/usr is one of the most important directories in Linux.
it mainly contains installed programs, libraries, documentation, and other read-only/shared resources used by users and applications.

Note:
/usr = programs and resources that are normally shared by the system



= cli
ls /
ls /usr

/usr: 
    bin        // Most user commands/programs
    include    // Header files for development
    lib        // Libraries used by programs
    lib64
    local        // Locally installed software  
    sbin        // System administration programs
    share      // Architecture-independent data
    src        // Source code, often kernel-related


------------------------------

= /usr/bin
contains a huge number of executable programs.

eg:
    ls
    cp
    mv
    grep
    find
    git
    python3
    ssh
    curl


Note: On many modern Linux distributions, /bin is actually a symbolic link to /usr/bin.

= Check
ls -ld /bin  //output -> /bin -> usr/bin
// This is called usr merge.


= Find where a command comes from
which python3  // output -> /usr/bin/python3
type -a python3 

------------------------------
= /usr/sbin
contains programs primarily used for system administration.

eg:
  useradd
  userdel
  groupadd
  sshd

= Check
which useradd  // output -> /usr/sbin/useradd

Note:
The distinction between /usr/bin and /usr/sbin is less strict on modern Linux systems, because regular users can sometimes execute programs from /usr/sbin.
The important idea is: /usr/sbin traditionally contains system-administration commands.

------------------------------
= /usr/lib
contains libraries and supporting files used by programs.

Conceptually:

Program
  │
  ├── executable
  │      ↓
  │   /usr/bin
  │
  └── libraries
         ↓
      /usr/lib


// This is similar to application dependencies in modern development.

This directory contains architecture-independent data.

eg:
/usr/share/doc
/usr/share/man            // Linux manual pages are commonly stored here.
/usr/share/icons
/usr/share/applications
/usr/share/locale

= /usr/local
This is especially important for DevOps.
It is intended for software installed locally by the administrator, rather than software managed by the operating system's package manager.

= Typical structure
/usr/local/
├── bin        // commonly used for locally installed executable commands.
├── lib
├── share
└── ...

= /usr Vs /var
/usr
Mostly contains:
        Programs
        Libraries
        Documentation
        Shared resources

/var
Most contains:
        Logs
        Caches
        Databases
        Spools
        Application changing data


Think:
        /usr
         │
         ├── Programs
         ├── Libraries
         └── Static/shared resources
                ↓
           Mostly doesn't change frequently
        
        
        /var
         │
         ├── logs
         ├── cache
         ├── databases
         └── application data
                ↓
           Changes frequently
        
------------------------------
= /usr Vs /opt

/usr
Normally contains software integrated into the Linux system/package-management structure.


/opt
Often used for optional/add-on third-party software.


Rule: 
/usr → system-integrated software
/opt → optional/third-party application packages

= Don't manually delete things from /usr
⚠️ Be careful.
Do not randomly do: sudo rm -rf /usr/...
You can break your Linux installation.


Deleting important files from:
/usr/bin
/usr/lib

can cause commands or applications to stop working.
Instead, use your distribution's package manager.

For Ubuntu/Debian: sudo apt install package-name / sudo apt remove package-name
For Fedora/RHEL: sudo dnf install package-name / sudo dnf remove package-name
