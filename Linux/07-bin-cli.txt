= What is /bin?
/bin stands for binary.
In Linux, a binary is an executable program — something the operating system can run.
bin is a directory containing essential executable commands needed for basic system operation.


--------------------------------------------
= What does "binary" mean?'
A binary executable is different from a shell script.

ls -l /bin
ls -ld /bin

= Why was /bin separated from /usr/bin?
Historically, Linux systems separated files into areas such as:
/bin
/usr/bin
/sbin
/usr/sbin


= Note:
/bin
    Essential commands needed for basic operation

/usr/bin
    Additional user commands

/sbin
    Essential system administration commands

/usr/sbin
    Additional system administration commands


The distinction is less strict on modern distributions because of /usr merging.
--------------------------------------------
= /bin vs /usr/bin

/
├── bin
│   ├── ls
│   ├── cp
│   ├── mv
│   ├── rm
│   └── cat
│
└── usr
    └── bin
        ├── git
        ├── python
        ├── vim
        └── ...


/
├── bin -> usr/bin
│
└── usr
    └── bin
        ├── ls
        ├── cp
        ├── mv
        ├── git
        └── ...

So don't assume that every Linux system physically stores commands separately in /bin.

--------------------------------------------
= How does Linux find ls?
When you type: ls 
the shell uses the PATH environment variable.
Check it: echo $PATH
You might see: /usr/local/bin:/usr/bin:/bin:/usr/local/sbin:/usr/sbin:/sbin



= Note:
You type:
    ls
     │
     ▼
Shell checks PATH
     │
     ├── /usr/local/bin
     ├── /usr/bin
     ├── /bin
     └── ...
          │
          ▼
       finds ls
          │
          ▼
       executes it
