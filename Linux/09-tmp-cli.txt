= Temporary file
/tmp -> Linux's temporary workspace
/tmp is a directory used by Linux programs and users to store temporary files that are needed for a short period of time.


Note:
Be careful about relying on files in /tmp permanently. Temporary directories can be cleaned automatically.


eg:
  /tmp/app.tmp
  /tmp/download.tmp
  /tmp/session123
  /tmp/cache-file
  /tmp/build-12345

Different applications use different naming conventions.
Don't assume every file has a .tmp extension.
The temporary file doesn't need to permanently remain on the system.
A temporary file can have any name.

= Why does /tmp exist?
Programs frequently need temporary storage.


------------------------------------------------
= /tmp vs /var/tmp

| Directory  | Purpose                         | Expected lifetime  |
| ---------- | ------------------------------- | ------------------ |
| `/tmp`     | Temporary files                 | Short-lived        |
| `/var/tmp` | More persistent temporary files | Can survive reboot |


/tmp
Used for temporary data that doesn't need to survive a reboot.

/var/tmp
Used for temporary data that may need to remain available after reboot.

Think:
/tmp
   ↓
"I need this temporarily."

/var/tmp
   ↓
"I need this temporarily,
 but it may need to survive reboot."


------------------------------------------------
= Does /tmp get deleted automatically?
Potentially, yes.
The exact cleanup mechanism depends on the Linux distribution and configuration.
Many modern Linux systems use systemd-tmpfiles to clean temporary files.

------------------------------------------------
= Important: Don't use /tmp for permanent data
Suppose you have an important application configuration: /tmp/my-app-config.conf
That's generally a bad place for permanent configuration.
Why?
Because /tmp is intended for temporary data and files may be cleaned up.

Instead, depending on what you're storing, you might use: /etc
for system configuration: /var/lib
for persistent application data or user data: /home/


Think:
Temporary
    ↓
/tmp

Configuration
    ↓
/etc

Persistent application state
    ↓
/var/lib

User files
    ↓
/home
